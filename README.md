## 🪟 Windows 安装

1. 在 Release 附件中选择“Windows端安装包”并下载，双击 `.exe` 文件运行安装。
2. 如果出现 Microsoft Defender SmartScreen 蓝色提示，点击 **“更多信息” → “仍要运行”**。
3. 安装完成后，从开始菜单打开 **ChatGPT账号工具-711EV**。

> ℹ️ 当前安装包未配置 Windows Authenticode 商业签名，首次运行出现 SmartScreen 提示属于正常情况。

---

## 🍎 macOS 安装

1. 在 Release 附件中选择“macOS端安装包”并下载通用版 DMG，双击打开后，将 **ChatGPT账号工具-711EV** 拖入“应用程序”文件夹。
2. 首次打开时，如果出现 **“Apple 无法验证应用”** 或 **“来自身份不明的开发者”** 的提示，请按下面步骤放行一次：
   - 打开 **系统设置 → 隐私与安全性**。
   - 滚动到“安全性”部分，在被阻止的应用提示旁点击 **“仍要打开”**。
   - 使用 Touch ID 或管理员密码确认，再点击 **“打开”**。
3. 完成放行后，从“应用程序”中双击即可正常运行。

> ℹ️ 当前 macOS 发布包未进行 Apple Developer ID 签名和公证，因此首次运行可能需要手动放行；完成一次后即可正常打开。
